# Instrucciones para Claude

## Git

- **Nunca hagas commits ni push automáticamente.** Espera siempre a que el usuario lo pida explícitamente.
- Cuando el usuario pida un commit, usa el git config existente sin modificarlo (no cambies user.name ni user.email).
- No añadas `Co-Authored-By: Claude` en los mensajes de commit salvo que el usuario lo pida.
